# Checklist

## 账号系统
- [x] 注册功能（邮箱格式校验 + 密码≥6 位）可用，密码经 bcrypt（cost≥10）加密存储
- [x] 重复邮箱注册返回 409
- [x] 登录功能（bcrypt.compare 校验）可用，签发 JWT（HS256，7 天）写入 httpOnly Cookie
- [x] 登录失败返回统一错误"邮箱或密码错误"（防枚举）——含两种失败分支虚拟比较，避免时间差
- [x] 退出登录清 Cookie 并跳转登录页
- [x] 未登录访问受保护页面被 middleware.ts 路由守卫拦截
- [x] 数据隔离：A 用户无法查到 B 用户的班级/学生/沟通记录（API 层 user_id 过滤 + 归属校验）

## 班级管理
- [x] 可创建班级（名称≤30 字 + 年级下拉 1-6）
- [x] 班级列表显示当前用户所有班级
- [x] 可编辑班级名称/年级（校验归属）
- [x] 删除班级有弹窗确认，级联删除关联学生/记录
- [x] 一个用户可创建多个班级

## 学生管理
- [x] 可手动添加学生（姓名必填≤20 字、性别选填、标签逗号分隔存 tags 字符串）
- [x] 学生列表按班级展示
- [x] 可编辑学生信息
- [x] 删除学生有确认弹窗（外键 SET NULL → 记录保留但 student_id 为 null）
- [x] 批量导入：粘贴文本 `姓名,性别,标签1;标签2` 正确解析（跳过空行/姓名缺失行，性别非男女视为空，标签分号拆分逗号拼接），返回成功/跳过数
- [x] 学生详情页可查看历史沟通记录

## 沟通记录
- [x] 可记录一次沟通事件（选学生/家长消息/回复/策略/风险/结果）
- [x] 字段完整：parent_message、reply、strategy、risks、result
- [x] 沟通记录列表按班级/学生查看，显示时间、学生（无则"未关联"）、消息摘要前 30 字
- [x] 沟通记录详情可查看完整家长消息、回复、策略、风险、结果
- [x] 结果字段为简单文本框，可编辑保存记录后续进展

## AI 话术生成（核心）
- [x] 话术生成页含家长消息输入框、学生选择器、生成按钮、隐私提示、鼓励语
- [x] 点击"生成话术"调用 DeepSeek（deepseek-chat）返回 1-3 条话术
- [x] 输出含沟通策略提示
- [x] 输出含风险点提示
- [x] 输出为结构化 JSON `{scripts,strategy,risks}`，解析失败降级纯文本
- [x] 选中学生后调用该学生标签和档案作为上下文注入
- [x] 生成的话术可编辑（textarea）
- [x] 可保存到沟通记录并关联学生
